## How to Use This Index

1. **Default workflow:** Read `triet-writing-profile.md` — it has everything extracted and categorized.
2. **Genre-specific writing:** If asked to write in a specific genre (e.g., "write a legal brief"), read the relevant source files above for deeper immersion in that register.
3. **Adding new samples:** When new writing is provided, add the file to `./samples/`, add an entry here with relative path, key patterns, and best-use description. Then update `triet-writing-profile.md` with any new patterns discovered.
4. **Profile refresh:** Periodically re-read source files and update the profile with any patterns that were missed or that have evolved.
